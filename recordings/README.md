# Recordings

Real performances of the pieces (public domain or free licence only: this folder is published),
offered by the Interpretation selector, played with the score following them, and listed in
`src/recordings.ts`. None yet.

A recording has to be of the same version as the score: another arrangement (other notes, not
just another key or other repeats) can't be lined up with it.

Recordings for trying out that may not be published go in `local-recordings/` (git-ignored,
served by the dev server only) and `LOCAL_RECORDINGS`.
